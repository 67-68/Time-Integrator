## Theory Base

### 认知科学基础：TI的诞生是为了什么
- Dual-brain model
system 1 and 2. We need our system 2 to control our system 1, use TI

- 人类大脑和记忆的不可靠性
鉴于它们的这种性质，记忆是不准确的，而必须有一个记录来帮助记录时间数据，否则就会根据自身的感情扭曲

### 方法论：TI如何达到它的理想状态？
- 自我洞察驱动开发
对于每一个功能，一定是我有这个需求才会去开发；对于每一个分析，一定是我的确遇到了这个问题才会把它写进TI。由此，避免假大空，浮华的产品
这如何帮助了TI管理时间呢？避免了不重要/不需要功能的任意添加，干扰视线

- 苏格拉底对话模型
TI永远不会直接对用户的数据做出定论和归因，而是像苏格拉底一样和用户对话，prompt用户自己归因
这帮助了TI成为一个有效的时间管理和分析软件，因为每一条数据异常的原因都可能是不同的，有着不同的概率，但又遵循基本的法则，大部分的数据都是一样的
同时，这给予了用户基本的尊重，给自己留出了不至于尴尬的空隙（信誓旦旦的归因，然后错误）

- 时间自我模型
这是TI的基本叙事框架，在这个框架下，TI把数据编织成为故事，使用当前的自己和过去，未来的自己比较，得出进步和计划的实现程度。在这之下，使用洞察，表扬和警告几种卡片类型帮助进一步的叙事。
这帮助了TI分析时间，因为一个叙事远比简单的数据更加深入人心，更加容易理解和督促用户做出改变

### 方法：TI具体如何分析，管理时间？
- 基态流动模型和任务流分类法
在这个模型下，人的自然状态，也是应该追求的状态并非静止不动，而是流淌着的，因此这引出了最终的目的：追求基态流动。
以此为基础，任务流分类法被创造，对于不停歇的，人生的流动，不同的任务流从时间中涌现出来：长河中，水流并非都是一类，而根据地势，出现了湍急的溪流，沉默的死水和高耸的瀑布。任务流从不同行动单元的整合中涌现出来，揭示了一段叙事，例如，今天上午做了学习，做题，然后吃饭，就是一段"学习"的任务流

- 判断力层次模型：我们如何判断一个行动，一段任务流的好坏
和未来，过去的自己，以及和生理的限制比较。

- 纯粹意图：强化/警惕模型
在一个分析，一张卡片中，只能包含要么是强化，要么是警惕的叙事，否则制造焦虑，吹毛求疵

- 数据神圣本地化
数据被存储在本地，不用担心丢失的问题

### 最终，核心，基础
1.  **基座（数据）：** 我们捕捉每一个无意义的**时间碎片 (`actionUnit`)**。
2.  **中层（模式）：** 我们帮助你看到，从这些碎片中**涌现 (`Emergence`)**出的、代表你“意识-行动”模式的**任务流 (`Task Stream`)**。
3.  **顶层（智慧）：** 我们通过**时间自我模型 (`Temporal Self Model`)**（与过去/未来的自己比较），来评估这些“任务流”的健康状况，最终引导你，去实现那个理想的、可持续的**基态流动 (`Ground State Flow`)**。

正如意识从时间中涌现，任务流从行动单元中涌现，被评判，主动的观察，管理自己的任务流
